# 怎么导出笔记为Word或PDF

Pandoc 是一个文档格式转换器，能把你的 `.md` 笔记变成 Word、PDF、HTML 等格式。

## 怎么用

1. 打开任意笔记
2. 按 **Ctrl+P** 打开命令面板
3. 搜索 **Pandoc**
4. 选你要的格式：
   - **Word (.docx)** → 交作业、写报告
   - **PDF** → 打印、发别人看
   - **HTML** → 做网页

## 文件存在哪

导出文件会放在**原笔记同一个文件夹**里，不会乱跑。

## 注意

- 导出一定会生成文件，没有"只预览"模式
- 点错了直接删掉就行，不影响原笔记
