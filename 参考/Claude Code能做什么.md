# Claude Code 能做什么

> 你的工人（Agent），听指挥干活

---

## 能干的

| 类别 | 具体能做什么 | 举例 |
|------|-------------|------|
| 写代码 | Python、HTML、SQL、JavaScript | 生成分析脚本、做网页 |
| 数据分析 | 读CSV/Excel → SQL分析 → 可视化 | 巴西电商10万订单分析 |
| 生成文件 | Word、Excel、PPT、PDF、CSV、图片 | 四件套一条命令搞定 |
| 做网页 | HTML + ECharts + cloudflared外链 | 仪表盘、生日页面 |
| 操作电脑 | 装软件、卸程序、查配置、清文件 | winget + 系统优化 |
| 查资料 | 联网搜索、读网页、看文档 | 工具定价、方案调研 |
| 管知识 | 写笔记、建链接、优化Obsidian | 双向链接、全链路工作流 |

## 不擅长 / 需要配合的

| 类别 | 表现 | 正确做法 |
|------|------|---------|
| Word 排版 | python-docx 能写内容，但格式不精致 | AI 出内容 + 手动套模板 |
| PPT 设计 | 能塞文字图片，做不出设计师水平 | AI 出内容 + 自己拖布局 |
| 视频生成 | 只能拼图片成视频，不能创作画面 | 交给即梦/Seedance |
| 图片识别 | 能读但精度一般 | 用字幕/文字替代 |

## 最强组合

| 场景 | 分工 |
|------|------|
| 写论文 | DeepSeek 出内容 + Python 套模板 + 你最后检查 |
| 做报表 | SQL 取数 + Python 写 Excel + 图表自动画 |
| 搞项目 | Claude Code 写代码 + DeepSeek 当大脑 + Obsidian 存知识 |
| 学新东西 | AI 讲白话比喻 + 你用自己的话复述 + 记笔记链接 |
