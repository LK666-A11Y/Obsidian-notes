# Obsidian 使用技巧

## 核心功能

### 1. 双向链接 `[[]]`
- 笔记之间互相引用
- 写 `[[另一篇笔记]]` 自动创建链接
- 点链接直接跳过去

**你的用法：**
```
今天跑 SQL 发现运费占比 35%
→ 在日记里写 [[跨境电商利润分析]] 引用项目笔记
```

### 2. 标签 `#`
- 给笔记打标签
- 比如 `#SQL` `#跨境电商` `#业财融合`
- 点标签看到所有相关笔记

### 3. 图谱视图
- 左侧栏 → 点 Graph View
- 看到所有笔记之间的关联网
- 点越多、关联越多 = 知识越密

### 4. 模板
- 设置 → 核心插件 → 打开"模板"
- 创建模板笔记，每次新建用 Ctrl+T 插入

### 5. Dataview 插件（进阶）
- 把笔记当成数据库来查
- 以后笔记多了再装

## 附件用法

### 链接外部文件
```
[打开仪表盘](../学习/仪表盘.html)
[查看Excel](附件/文件名.xlsx)
```

### 双向链接笔记
```
[[2026-05-24 学习记录]]
```

| 写法 | 效果 |
|------|------|
| `[[笔记名]]` | 跳到另一篇笔记 |
| `[文字](路径)` | 打开电脑上的任意文件 |
