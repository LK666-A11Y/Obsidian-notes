# 第15篇 · Claude Code 多工人并行

> 创建时间：2026-05-25

> 不止一个工人，是一个工头管多个工人同时干活。

## 一句话

复杂任务拆成互不依赖的小块，同时扔给多个 Agent 并行处理，一轮对话出结果。

## 比喻

厨房里：
- 串行 = 一个厨师先切菜、再炒菜、再烧水（慢）
- 并行 = 三个厨师同时切菜、炒菜、烧水（快）

## 什么时候用

| 场景 | 并行拆法 |
|------|----------|
| 简历投递 | 同时搜 3 个平台的岗位 + 对比薪资 |
| 数据分析 | 同时跑 4 条 SQL + 画 2 张图 |
| 学新概念 | 同时搜定义、搜案例、搜教程 |
| 项目推进 | 一边改代码、一边写文档、一边搜资料 |

## 什么时候不用

- 任务之间有关联（B 需要 A 的结果才能做）— 只能串行
- 非常简单的事（一句话搞定没必要拆）

## 实操演示

```
用户：帮我查项目状态 + 数据库大小 + 照片数量 + 搜实习
Claude Code：同时启动 4 个工人，一轮全回来
```

结果：4 件事，一轮对话，跟做一件事花的时间一样。
