## 学会的新概念

| 概念 | 我的理解 |
|------|----------|
| Agent | 有手的 AI，不光聊天还能动手建文件、跑代码、装工具 |
| MCP | 万能插头，把不同系统的数据统一格式连到 AI |
| Skill | AI 的扩展功能，像给手机装 App |
| SQL | 跟数据库说话的语言，SELECT、JOIN、GROUP BY |
| Python 脚本 | 写好的自动化步骤，双击就跑 |
| cloudflared tunnel | 把本地网页变成一个别人能打开的公网链接 |

## 数据分析结果（巴西电商 Olist）
- 总订单 98,666 单，商品金额 1,359 万雷亚尔
- **运费占比 16.57%**（每100块商品，16块花在运费上）
- **运费最高的城市** Santarem（PA）运费占比 35%
- **Top 3 品类**：健康美容、手表礼品、床浴桌用品
- **月度趋势**：2017 年 11 月数据暴涨（黑色星期五）
- 结合行业情报：美客多运费最高降 40%，亚马逊巴西配送费最高降 89%
