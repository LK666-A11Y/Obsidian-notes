# AI 时代的人机协作

## 核心发现

> claude.md 本质就是你的 **AI 身份证**——换任何新 AI，丢过去，30秒它就懂你。

大部分人要学提示词工程才明白这件事，但实际操作很简单：

## 你的 AI 身份证包含什么

| 要素 | 例子 |
|------|------|
| 你是谁 | 财务专业、二本、小白 |
| 你怎么学 | 比喻、白话、实操 |
| 你的项目 | 跨境电商利润分析 |
| 你的工具 | VS Code + Power BI + Obsidian |
| 你的红线 | 做事前先问我 |

## 为什么管用

- AI 没有记忆，但 `claude.md` 是**持久记忆**
- 写一次，所有对话都生效
- 换平台（DeepSeek、千问、任何新AI）直接丢过去
- 不需要每次重新自我介绍
