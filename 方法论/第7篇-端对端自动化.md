# 第16篇 · 端对端自动化

> 创建时间：2026-05-26

> PC 端触发 → Python 干活 → 内容推到手机端。不需要 AI 在线，系统级自动跑。

## 是什么

跟定时提醒的区别：

| | 定时提醒 | 端对端自动化 |
|------|----------|------------|
| 谁跑 | 靠 AI 在线 | 系统任务计划程序 |
| 关机能跑吗 | 不能 | 下次开机补跑 |
| 产出 | "该背单词了" | 新内容直接送到手机 |
| 依赖 | Claude Code 必须开着 | 只依赖电脑开机 |

## 核心配方（3 样东西）

1. **Windows 任务计划程序** — 触发器，管"什么时候跑"
2. **Python 脚本** — 工人，管"具体干什么"
3. **QQ 邮箱 SMTP** — 通道，管"推到手机哪里"

---

## SMTP 是什么

> 快递小哥。你把包裹（邮件）交给它，它负责送到目标邮箱。

**全称**：Simple Mail Transfer Protocol（简单邮件传输协议）

**比喻**：你寄快递需要：
- 快递公司地址 → `smtp.qq.com`（QQ 邮箱的快递站点）
- 你的 ID → `3265599357@qq.com`（寄件人身份）
- 取件码 → SMTP 授权码（证明是你本人，不是 QQ 密码）

Python 把邮件打包好，通过 SMTP 交给 QQ 邮件服务器，QQ 再推到你的手机。

**怎么拿到授权码**：QQ 邮箱网页 → 设置 → 账户 → POP3/SMTP 服务 → 开启 → 短信验证 → 拿到一串字母（rhd...开头那个）

## QQ 邮箱闭环（完整链路）

```
┌─────────────────────────────────────────────────────┐
│  PC 端（你的电脑）                                    │
│                                                      │
│  任务计划程序 ──触发──▶ Python 脚本                    │
│                          │                           │
│                          │ 生成邮件内容                │
│                          ▼                           │
│                     smtplib.SMTP_SSL()               │
│                     地址：smtp.qq.com:465             │
│                     登录：QQ号 + 授权码（不是密码）     │
│                          │                           │
└──────────────────────────┼───────────────────────────┘
                           │ 互联网
                           ▼
┌─────────────────────────────────────────────────────┐
│  QQ 邮件服务器                                        │
│  收件 → 存到你的邮箱 → 推通知到 QQ 客户端               │
└─────────────────────────────────────────────────────┘
                           │
                           ▼
              ┌─────────────────────────┐
              │  手机 QQ 弹提醒          │
              │  点开就是邮件内容         │
              └─────────────────────────┘
```

4 个环节缺一不可：
1. 触发器（任务计划程序）→ 到点干活
2. 脚本（Python）→ 生成内容 + 调 SMTP
3. 授权码 → 证明身份，不是 QQ 密码
4. QQ 服务器 → 接收邮件 + 推手机通知

## 案例：每日知识推送

```
每天 8:00
  → 任务计划程序唤醒电脑
  → Python 随机抽 obsidian 一篇笔记
  → DeepSeek AI 提炼 3-5 条要点 + 思考问题
  → QQ 邮箱发到 3265599357@qq.com
  → 手机 QQ 弹提醒，点开即看
```

三种情况全覆盖：
- 开机 → 准点发
- 睡眠 → 唤醒电脑 → 发完睡回去
- 关机 → 下次开机立刻补发

## 关键认知

- 端对端的核心不是 AI，是**系统级触发器 + 自动化脚本**
- AI 是中间加工层，不是调度层
- Windows 任务计划程序是免费内置的，不需要装任何东西
